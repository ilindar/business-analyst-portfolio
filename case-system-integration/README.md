# Интеграция CRM «WebStyle» с сервисом MadeTask

## Описание проекта
Разработка технического задания на интеграцию CRM с сервисом MadeTask для:
- автоматизации создания задач и управления исполнителями;
- автоматических выплат по реквизитам исполнителей;
- синхронизации статусов между системами.

## Роль в проекте
Системный аналитик (разработка ТЗ, проектирование интеграции, анализ API).

## Основные результаты
- Проанализирован текущий бизнес-процесс (as-is) и спроектирован целевой (to-be).
- Разработаны UML-диаграммы последовательности для ключевых сценариев.
- Проведён анализ API MadeTask: методы, форматы, ограничения.
- Составлены функциональные и нефункциональные требования.
- Разработан план реализации с приоритизацией задач.
